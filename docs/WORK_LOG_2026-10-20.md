## 1. MỤC TIÊU VÀ PHẠM VI DỰ ÁN
- **Mục tiêu:** Xây dựng trọn gói hệ thống Web Quản lý Trung tâm Ngoại ngữ theo chuẩn công nghiệp, hiện thực hóa toàn bộ **82 yêu cầu chức năng (FR-01 đến FR-82)** thuộc 11 phân hệ, hỗ trợ 5 nhóm đối tượng (Quản trị viên, Nhân viên học vụ, Giáo viên, Học viên, Phụ huynh).
- **Tech Stack:**
  - **Backend:** Python 3.14+, FastAPI, SQLAlchemy 2.0, Pydantic v2, SQLite (`language_center.db`), PyJWT, Bcrypt, TestClient (Httpx).
  - **Frontend:** React 19 thuần túy (JavaScript JSX), Vite 8, Tailwind CSS v4, Lucide React, Axios.
