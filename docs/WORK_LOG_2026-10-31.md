## 1. TỔNG QUAN YÊU CẦU & KẾT QUẢ ĐÃ THỰC HIỆN

### 1. Thiết kế toàn diện Database Schema trên Prisma ORM
- **File nguồn:** [prisma/schema.prisma](file:///d:/OOAD/prisma/schema.prisma) (Chuẩn hóa cho PostgreSQL / MySQL) và [prisma/schema.sqlite.prisma](file:///d:/OOAD/prisma/schema.sqlite.prisma) (Tương thích SQLite cho phát triển cục bộ).
- **Cấu trúc Models:** Bao gồm đủ 12 thực thể cốt lõi:
  1. `User`: Tài khoản người dùng (5 roles: ADMIN, ACADEMIC_STAFF, TEACHER, STUDENT, PARENT), mật khẩu băm Bcrypt, quản lý khóa tài khoản (lockout) và OTP reset.
  2. `Course`: Khóa học và chuẩn đầu ra (IELTS, TOEIC), thời lượng, học phí.
  3. `Student`: Hồ sơ học viên (1-1 với User), mã học viên, ngày sinh, địa chỉ, trạng thái.
  4. `Teacher`: Hồ sơ giáo viên (1-1 với User), mã giáo viên, chuyên môn, bằng cấp.
  5. `Classroom`: Cơ sở vật chất phòng học, tòa nhà, sức chứa chỗ ngồi.
  6. `Class`: Lớp học, khóa ngoại khóa học và giáo viên, sĩ số tối đa, sĩ số thực tế, trạng thái.
  7. `ClassStudent`: Bảng thành viên lớp học Many-to-Many với ràng buộc `@@unique([classId, studentId])`.
  8. `EnrollmentRequest`: Đơn đăng ký ghi danh lớp học, lý do từ chối, duyệt bởi học vụ.
  9. `ScheduleSession`: Lịch học từng buổi, xếp lớp, phòng học, giáo viên, cờ xác nhận và kiểm tra xung đột.
  10. `GradeRecord`: Quản lý bảng điểm thành phần (chuyên cần 20%, giữa kỳ 30%, cuối kỳ 50%), điểm tổng kết và khóa điểm.
  11. `CourseProgression`: Thẩm định điều kiện tiên quyết và lộ trình chuyển khóa học.
  12. `ParentStudent`: Liên kết tài khoản phụ huynh với học viên được giám hộ.

### 3. Cấu hình Scripts quản trị trong Root `package.json` & `.env.example`
- Bổ sung file [package.json](file:///d:/OOAD/package.json) tại thư mục gốc với các lệnh tiện ích:
  - `npm run prisma:generate`: Sinh mã client an toàn kiểu dữ liệu.
  - `npm run prisma:migrate`: Chạy migration cho PostgreSQL.
  - `npm run prisma:push`: Đẩy schema trực tiếp vào CSDL mà không cần tạo migration file.
  - `npm run prisma:seed`: Nạp dữ liệu mẫu vào CSDL.
  - `npm run prisma:studio`: Mở giao diện trực quan Prisma Studio trên trình duyệt.
  - `npm run prisma:sqlite:push` & `npm run prisma:sqlite:studio`: Lệnh thao tác trực tiếp với SQLite.
- Tạo file [.env.example](file:///d:/OOAD/.env.example) hướng dẫn cấu hình chuỗi kết nối PostgreSQL và SQLite.
